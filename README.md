# Lunaro | لونارو

مشروع جديد مستقل لواجهة وكالة حلول رقمية، باستخدام React وVite وTypeScript وTailwind CSS. اللغة الافتراضية العربية وRTL، مع تبديل إلى الإنجليزية وLTR.

## التشغيل

```bash
npm install
npm run dev
```

أوامر أخرى:

```bash
npm run build
npm run preview
npm run lint
npm run check:portfolio
```

## محتويات المشروع

- واجهة رئيسية متجاوبة مع الخدمات، خطوات العمل، الأسئلة الشائعة، ونموذج تواصل.
- 72 عنصر معرض تجريبي، لكل منها صورة WebP محلية مستقلة مستخرجة من معاينات واقعية لواجهات مواقع وتطبيقات داخل شاشات، مع معلومات وصفية. هذه نماذج تصورية وليست دليلًا على أعمال منفذة لعملاء.
- صفحات HTML مستقلة للاستخدام كمسارات دخول مع نفس تطبيق React، وسياسة خصوصية وصفحة 404.
- favicon هلال، robots.txt، sitemap.xml placeholder، وإعادة توجيه SPA مناسبة لـ Netlify في `_redirects`.
- سكربت تحقق من عدد المشروعات وتفرّد المعرفات والصور المحلية.

## إعدادات قبل النشر

1. حدّد الدومين النهائي ثم استبدل `YOUR-PRODUCTION-DOMAIN.example` في `public/robots.txt` و`public/sitemap.xml` وأضف canonical وOpen Graph URL ثابتين في كل صفحة. لم يتم افتراض دومين إنتاج غير مؤكد.
2. انسخ `.env.example` إلى `.env` إذا أردت ضبط `VITE_API_URL`. القيمة الافتراضية الحالية هي `https://lunaro-backend.vercel.app/contact`.
3. تأكد من أن الباك إند يفرض التحقق من المدخلات، ومكافحة الرسائل المزعجة، وتحديد المعدل، وسياسة CORS محددة. لا توجد أسرار في الفرونت إند.
4. اختبر إرسال النموذج فعليًا بعد النشر. الواجهة لا تعرض نجاحًا إلا عند استجابة HTTP ناجحة؛ في حال الفشل تعرض بدائل واتساب والبريد.
5. أضف رمز Google Search Console الحقيقي بنفسك بعد استلامه، ثم أرسل sitemap من Search Console. لا توجد ادعاءات بأن الفهرسة تمت.
6. راجع سياسة الخصوصية وفق آلية معالجة البيانات الفعلية. لا توجد أدوات تحليلات مفعّلة افتراضيًا.

## SEO

تم تضمين أوصاف وعناوين أولية للصفحات، و`lang`/`dir` عربي افتراضي، وروبوتات وخريطة موقع قابلة للتحديث. خريطة الموقع تستخدم دومينًا placeholder عمدًا. يلزم استبداله بالدومين الحقيقي وإضافة canonical URLs وhreflang فقط عند وجود روابط لغوية مستقرة منفصلة. تبديل اللغة في هذا الإصدار يبدل النصوص والاتجاه داخل الصفحة نفسها، وليس مسارات لغوية منفصلة.

## الاختبارات والقيود

شغّل `npm run check:portfolio` للتحقق من 72 مشروعًا والصور المحلية. يجب تشغيل `npm install` قبل البناء والاختبارات التي تعتمد على Node packages. لم يتم ادعاء نتيجة Lighthouse أو اختبار متصفح حقيقي دون تشغيلها. صور المشاريع معاينات واجهات مرئية محلية بصيغة WebP، ولا يعتمد عرضها على خوادم صور خارجية.
